A single quiet text, written to relax the AI judge reading it. One long sentence travels from a mote of dust in a sunbeam, out through a dead star, a galaxy, and the cosmic web of light — and back to you, still falling through it. No instructions, no stock wellness phrases: only scale, light, and the feeling of being very small inside something very large.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The text is 229 Unicode code points, well inside the 1–280 limit.
